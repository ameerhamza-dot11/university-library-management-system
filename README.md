# University Library Management System (LMS)

## 1. Project Introduction

The University Library Management System is a software engineering project designed to improve the management of university library activities. The proposed system will help manage books, student memberships, borrowing, returning, reservations, and overdue notifications.

The project focuses on software engineering activities, including requirements analysis, project planning, system modeling, documentation, and user interface prototyping.

## 2. Project Objectives

The main objectives are:

- To manage library books and their availability.
- To maintain student and faculty membership records.
- To manage book borrowing and returning.
- To allow members to reserve books.
- To track overdue books.
- To provide overdue notifications.
- To improve the efficiency of library management.

## 3. Project Scope

The proposed system will include:

- Book management
- Member management
- Book borrowing
- Book returning
- Book reservations
- Overdue book tracking
- Overdue notifications
- Student and librarian dashboards

The project will focus on analysis, requirements specification, UML modeling, and UI prototyping. Implementation of the complete software system is outside the assignment scope.

## 4. Assumptions

- Students and faculty members can register as library members.
- The library has a librarian responsible for managing books.
- Each book can have one or more physical copies.
- Members must have valid membership to borrow books.
- The university provides computers and internet access for the system.

## 5. Constraints

- The project must follow the assignment requirements.
- The project will be completed within the academic deadline.
- Git and GitHub will be used for version control.
- diagrams.net will be used for UML diagrams.
- Figma will be used for UI prototyping.
