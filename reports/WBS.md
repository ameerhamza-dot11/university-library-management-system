# Work Breakdown Structure (WBS)

## Project Name
University Library Management System

## 1. Project Planning
- 1.1 Define project objectives.
- 1.2 Identify project scope.
- 1.3 Identify assumptions and constraints.
- 1.4 Prepare project schedule.

## 2. Requirements Analysis
- 2.1 Identify stakeholders.
- 2.2 Collect stakeholder needs.
- 2.3 Identify functional requirements.
- 2.4 Identify non-functional requirements.
- 2.5 Prepare user stories.

## 3. SRS Documentation
- 3.1 Write project introduction.
- 3.2 Define system scope.
- 3.3 Document functional requirements.
- 3.4 Document non-functional requirements.
- 3.5 Prepare acceptance criteria.
- 3.6 Create traceability matrix.

## 4. UML Modeling
- 4.1 Create Use Case Diagram.
- 4.2 Create Class Diagram.
- 4.3 Create Sequence Diagram.
- 4.4 Create Activity Diagram.

## 5. UI/UX Design
- 5.1 Create Figma account.
- 5.2 Design login screen.
- 5.3 Design student dashboard.
- 5.4 Design book search screen.
- 5.5 Design book details and reservation screen.
- 5.6 Design librarian dashboard.
- 5.7 Connect screens using prototype interactions.

## 6. Testing and Review
- 6.1 Review project requirements.
- 6.2 Check UML diagrams.
- 6.3 Test prototype workflows.
- 6.4 Collect feedback from classmates.
- 6.5 Improve the prototype.

## 7. Final Documentation
- 7.1 Prepare project report.
- 7.2 Organize project files.
- 7.3 Review all deliverables.
- 7.4 Submit the final project.
