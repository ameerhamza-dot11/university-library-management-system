# Stakeholder Analysis

## Project Name
University Library Management System

## 1. Introduction
Stakeholder analysis identifies the people who interact with the University Library Management System or are affected by its operation.

## 2. Identified Stakeholders

| No. | Stakeholder | Role | Main Needs and Expectations |
|---|---|---|---|
| 1 | Students | Borrow and return books | Search books, check availability, reserve books, and view borrowing records. |
| 2 | Librarians | Manage library operations | Add books, update records, issue books, and manage returns. |
| 3 | Faculty Members | Use library resources | Search academic books, borrow books, and check availability. |
| 4 | University Administration | Supervise library activities | View library reports and monitor library operations. |
| 5 | System Administrator | Maintain the system | Manage user accounts, permissions, and system settings. |

## 3. Stakeholder Importance

- Students are the main users of the system.
- Librarians manage daily library activities.
- Faculty members use academic resources.
- University administration monitors library performance.
- System administrators maintain system security and settings.

## 4. Conclusion
Stakeholder analysis helps identify user needs and expectations. Understanding these needs will help develop a useful and effective University Library Management System.
